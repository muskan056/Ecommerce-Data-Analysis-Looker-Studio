# Ecommerce Data Analysis & Looker Studio Dashboard

E-commerce Data Analysis & Reporting Dashboard built using Looker Studio to analyze sales, revenue, orders, customers, and overall business performance.

## 📊 Project Overview

This project focuses on analyzing e-commerce business data and creating an interactive dashboard using Looker Studio.

The dashboard helps understand overall sales performance, customer behavior, order trends, and business performance through interactive charts, KPIs, and visualizations.

## 🎯 Objectives

- Analyze overall e-commerce sales performance
- Track revenue and order trends
- Understand customer behavior
- Identify top-performing products/categories
- Compare business performance across different dimensions
- Create an interactive and easy-to-understand reporting dashboard

## 🛠️ Tools & Technologies

- Looker Studio
- Excel / CSV
- Data Cleaning
- Data Analysis
- Data Visualization

## 📈 Dashboard Features

- Total Revenue
- Total Orders
- Total Customers
- Sales Performance Analysis
- Order Analysis
- Customer Analysis
- Product/Category Performance
- Interactive Filters
- Dynamic Charts and KPIs
