
# 🛒 Ecommerce Data Analysis & Reporting Dashboard

An interactive **E-commerce Data Analysis & Reporting Dashboard** built using **Google Looker Studio** to analyze sales performance, orders, profit, costs, customers, regions, categories, cities, and payment methods.

The dashboard provides an interactive view of overall business performance and helps identify important trends and patterns in e-commerce data.

## 🎯 Project Objective

The objective of this project is to create an interactive dashboard that helps businesses monitor and analyze their e-commerce performance through key KPIs and visualizations.

The dashboard focuses on:

* Sales performance
* Order volume
* Profit and cost analysis
* Regional performance
* Category-wise orders
* City-wise orders
* Payment method analysis
* Order trends over time

## 📈 Dashboard Features

### 1. Order Analysis

* Total number of orders
* Orders by region
* Orders by category
* Orders by city
* Order trends over time

### 2. Sales & Profit Analysis

* Total sales
* Total profit
* Total cost
* Overall business performance

### 3. Category Analysis

The dashboard allows users to filter and analyze orders across different product categories:

* Sports
* Home Decor
* Fashion
* Electronics
* Beauty

### 4. Payment Method Analysis

Orders can be analyzed based on different payment methods:

* UPI
* Net Banking
* COD
* Debit Card
* Credit Card

### 5. Interactive Filters

Users can dynamically filter the dashboard using:

* Category
* Order Date
* Payment Method
* Region
* Other available dashboard dimensions
